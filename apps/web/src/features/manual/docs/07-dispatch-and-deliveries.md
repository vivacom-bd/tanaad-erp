# Dispatch and Deliveries

This chapter covers loading a lorry, passing the gate, and proof of delivery. Orders only appear here once the cash is confirmed or the CEO has approved the credit.

Who uses this: storekeepers, gate staff, site managers, drivers, sales, and the CEO for viewing.

### Load lorry (Dispatch > Load lorry)
**Who:** storekeeper, gate, site manager, CEO, group admin  **Site:** all sites
**What it is for:** to scan every bundle onto a lorry, weigh it at the gate, and get the gate pass. Shortcut: g x.
**How to use it:**
1. Under "Ready to load", click the order. Orders still waiting for cash or the CEO are listed below, locked.
2. Type the "Driver" (or tap a recent driver) and choose the "Vehicle".
3. Press "Start loading". Use "Where to pick" to see which zones hold the bundles.
4. In "Scan Bundles onto Lorry", scan each sticker, or type its code. "Undo last" removes a wrong scan.
5. When every bundle is scanned, press "Weigh at the gate" and use the scale reading.
6. If the result is a pass, the gate pass is shown. Press "Load next order".
**Good to know:**
- The weight must be within the gate tolerance shown at the top (a percentage). The lorry is held if the weight is off, or if bundles are missing.
- When held, press "Recount" and weigh again, or press "Site Manager override". Only the Site Manager can release a held lorry. Write the reason first.
- The delivery note number is given when the gate passes.
- The "History" tab lists past dispatches. Press "Prepare share preview" to see the message. Nothing is sent.

### Deliveries (Dispatch > Deliveries)
**Who:** storekeeper, sales, site manager, driver, CEO  **Site:** all sites
**What it is for:** to follow every delivery note from the gate to the customer, and to record proof of delivery. Shortcut: g v.
**How to use it:**
1. Use the tabs to filter: "All", "Loading", "On the road", "Delivered", "Discrepancy" or "Held". Search by note, client, driver or receiver.
2. Click a delivery to open it.
3. Under "Proof of delivery", type the "Receiver".
4. Enter "Bundles counted". It starts at the number that left the gate.
5. Have the receiver draw a "Signature" and save it. Add a "Photo" if you can.
6. Press "Confirm delivery".
**Good to know:**
- Only storekeeper, gate, site manager and driver can confirm. Others see the delivery read-only.
- A signature is required before you can confirm.
- If fewer bundles were counted than left the gate, an exception goes to the CEO.
- Proof opens only after the gate pass. A held lorry cannot be confirmed.
- "Print delivery note" appears after the gate pass. "Export" downloads the list.
