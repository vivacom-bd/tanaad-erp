# Tanaad Management System: User Manual

A short guide to every page in the app, written for floor staff and managers. Each page entry says who can open it, what it is for, the steps to use it, and what to watch out for.

Start with **Getting started**, then go to the chapter for your work.

| 11 | [Group portal](11-group-portal.md) | CEO, group admin |
